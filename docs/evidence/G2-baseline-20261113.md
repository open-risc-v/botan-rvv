# botan G2：native A/B 与 riscv64 交叉基线（2026-11-13）

- 上游：`randombit/botan` @ `d138f9f`
- 构建：`configure.py --build-targets=static --minimized-build --enable-modules=sha2_32,aes,ctr --cpu=generic`
- 探针：`test/pkg_botan.cpp`（C++20）

| 路径 | native | riscv64 (rv64gc) |
|---|---|---|
| SHA-256（32 B） | `fnv=ab0624b961d45259` | 同左 |
| CTR(AES-256)（65536 B 密钥流） | `fnv=6b642726bef75efc` | 同左 |

## 三个坑

1. **Botan 3.x 要求 C++20**：探针必须 `target_compile_features(... cxx_std_20)`，否则
   `types.h` 直接 `#error "Botan 3.x requires at least C++20"`。
2. **`StreamCipher` 没有二维 `encrypt(vec, vec)`**：3.x 是 `cipher(in, out, len)`，
   `encrypt` 只接受单个 `span` 的就地版本。
3. **`configure.py` 不认 `--host`**：交叉要给 `--cc-bin=<triple>-g++ --os=linux
   --with-sysroot-dir=/usr/riscv64-linux-gnu --ar-command=<triple>-ar`。
